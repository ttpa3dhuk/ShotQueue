# ShotQueue

Личное Mac-приложение Азата для серии скриншотов с комментариями. Вход в задачу: `SESSION-RESUME.md`; затем `PLAN.md`, `DECISIONS.md`, `LESSONS.md`.

- Интерфейс разметки остаётся поверх исходного экрана. Отдельное окно редактора не подходит.
- Использовать системные API macOS и свой код. Snapik служит образцом поведения; его исходников на GitHub нет, код и оформление не копировать.
- Не менять горячие клавиши и разрешения других приложений ради теста.
- Перед испытанием массовой вставки сохранять снимки и текст на диск, чтобы сбой не потерял работу Азата.
- Статус и ограничения писать честно. README обновлять после проверки на живом Mac.
- Рабочая копия находится в `/Applications/ShotQueue.app`; `.build/ShotQueue.app` нужна только для сборки. Для управления GUI через компьютерный инструмент выбирать полный путь, потому что у копий один bundle ID.
