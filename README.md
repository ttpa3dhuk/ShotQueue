# ShotQueue

Снимки экрана с пометками для разговора с ИИ. Временное имя.

Азат делает несколько снимков подряд, отмечает на них нужные места и пишет короткие комментарии. Редактор должен появляться поверх того экрана, где сделан снимок. Отдельное окно Pinpoint оказалось неудобным, потому что уводило из рабочего места.

## Как пользоваться

1. Открыть `/Applications/ShotQueue.app`. Приложение покажет маленькую очередь справа и значок SQ в строке меню.
2. Нажать ⌥⌘S или «Новый снимок». Выделить область на замершем экране. Enter без выделения выбирает весь экран.
3. Поставить точку, рамку или стрелку. Рядом появится окно для комментария с кнопкой «Сохранить». В панели снизу нажать «Готово».
4. Повторить для других экранов. Очередь A, B, C сохраняется между запусками.
5. Открыть поле сообщения в Codex для VS Code и нажать ⌥⌘V. ShotQueue вставит каждый PNG, затем текст A1, A2 и так далее. Проверь результат и отправь сообщение сам.

Если другая программа уже заняла ⌥⌘S или ⌥⌘V, ShotQueue показывает запасную клавишу с ⇧ на кнопке очереди. Для вставки macOS просит «Универсальный доступ». Для снимков нужна «Запись экрана».

Снимки хранятся на Mac в `~/Library/Application Support/ShotQueue/`. «Очистить очередь» переносит старую серию в `Archive/`. Наш код не загружает снимки в сеть и не нажимает «Отправить» за тебя.

## Как устроено

Приложение написано на Swift и AppKit с системным ScreenCaptureKit. Это отдельная реализация по поведению, которое Азат показал в Snapik. Исходников Snapik на GitHub нет, только установочные пакеты.

## Как запустить

Установленная версия запускается из «Программ». Чтобы собрать исходники на этом Mac:

```bash
cd ~/VSCode/ShotQueue
./scripts/build.sh
.build/ShotQueue.app/Contents/MacOS/ShotQueue --self-test
./scripts/run.sh
```

Сборка использует уже установленный Xcode и сертификат Apple Development этого Mac. `run.sh` запускает копию из `.build/`; для обычной работы используй `/Applications/ShotQueue.app`.

## Где что лежит

| Путь | Что |
| --- | --- |
| `Sources/` | Код приложения |
| `scripts/` | Сборка и проверка |
| `~/Library/Application Support/ShotQueue/` | Локальные PNG, `session.json` и `session.md` |
| `PLAN.md` | Что готово и что дальше |
| `SESSION-RESUME.md` | Короткая точка продолжения |
