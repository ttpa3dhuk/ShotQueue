- ⭐ Решили сделать своё приложение для личного использования. Код пишем на Swift и AppKit; Snapik нужен для сравнения действий, его исходников на GitHub нет.

- Исходники сохранили в отдельном приватном репозитории `ttpa3dhuk/ShotQueue`.
- Нашли и исправили две ошибки первой сборки: поле заметки исчезало, а рендер оставлял чёрную половину PNG. Вставка текста без картинок тоже была промежуточным состоянием, теперь вставляются оба вида данных.
- 🎬 Для истории: Азат сказал: «пинпоинт мне не зашел» и «он не открывает отдельное окно» про нужное ему приложение.

- Установили подписанную сборку в «Программы». Рендер и архив прошли проверку, данные очереди совпали с резервной копией.

- В точке продолжения уже записано: Snapik удалён после сравнения, его пробные данные и разрешения убраны.
- 🎬 Для истории: после проверки Азат сказал: «Все, кайф, сохраняй результат, завершай сессию».

### Ночь: кисть с комментарием

- После первого завершения Азат вспомнил ещё один инструмент: закрасить ненужную зону кистью и оставить комментарий. Добавили свободный мазок шириной 24 точки, клавишу 4, номер и комментарий после отпускания мыши. Мазок можно отменить через общий стек ⌘Z.
- Первый тёмный цвет сливался с фоном. Азат прислал снимок A с комментарием «темно, надо светлее». Сначала сделали светло-серый, затем по его просьбе добавили выбор цвета и непрозрачности 10–100%.
- По умолчанию кисть розово-красная с непрозрачностью 50%. Каждый мазок хранит свой стиль, потому что изменение цвета не должно перекрашивать готовую разметку. Выбранный стиль сохраняется между запусками.
- ⭐ Азат прислал снимок B с розово-красным мазком B2. Цвет виден на тёмном фоне, изображение под мазком просматривается.
- Автопроверка прошла: координаты после обрезки, сохранение точек и стиля, комментарий, непрозрачный и полупрозрачный рендер, чтение старых очередей. Обновление установлено в «Программы» с резервной копией приложения и данных. Ручной выбор другого цвета и сохранение настройки после перезапуска на Mac пока не проверены.
- 🎬 Для истории: Азат уточнил: «чтобы вот эта замазанная область, на ней тоже комментарий появлялся».

### Продолжение ночи 29 октября: кисть и клавиатура

- Убрали тёмные точки на мазке: одинаковые координаты отбрасываются, прозрачность применяется один раз ко всему мазку. Автопроверка пауз и пересечений прошла.
- Добавили крестик, подсказки в неактивном приложении, значок буфера для вставки. Панель уменьшили до 188 × 44 точек, фон сделали прозрачнее.
- Для комментариев добавили меню «Правка» и обработку сочетаний по физическим клавишам, потому что копирование при русской раскладке требовало проверки. Выбор инструментов 1–4 работает независимо от фокуса кнопок, включая цифровой блок. Живую проверку копирования при русской раскладке пока не закрыли.
- Обновления подписаны и установлены, данные очереди сверены с резервными копиями. Подробности прежних остановок сохранены в истории Git.

## 2026-10-31 — очередь очищается сама

- Сборка, подпись и автопроверки рендера, архива, клавиатуры и срока очистки прошли. Установленная копия обновлена и запущена. Вид новых настроек и значков отдельно через GUI не проверяли.
- Резервные копии приложения и данных: `.build/backup-expiry-20261031-094410/` и `.build/backup-settings-20261031-100412/`.
