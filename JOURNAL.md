# Летопись ShotQueue

## 2026-10-27 — начали своё приложение для скриншотов

- Несколько дней Азат пользовался установленным Pinpoint и понял, что отдельное окно мешает. Приложение удалили с Mac.
- Нашли Snapik, который размечает снимок поверх текущего экрана и держит очередь. Поставили семидневную демоверсию, проверили один снимок с текстом A1–A3 в Codex.
- ⭐ Решили сделать своё приложение для личного использования. Код пишем на Swift и AppKit; Snapik нужен для сравнения действий, его исходников на GitHub нет.
- Собрали ShotQueue: выделение области и пометки поверх экрана, очередь на диске, отдельная клавиша вставки серии. Азат проверил три PNG и текст в черновике Codex, затем один новый снимок с комментариями без чёрного поля. Приложение поставили в «Программы».
- Исходники сохранили в отдельном приватном репозитории `ttpa3dhuk/ShotQueue`.
- Нашли и исправили две ошибки первой сборки: поле заметки исчезало, а рендер оставлял чёрную половину PNG. Вставка текста без картинок тоже была промежуточным состоянием, теперь вставляются оба вида данных.
- 🎬 Для истории: Азат сказал: «пинпоинт мне не зашел» и «он не открывает отдельное окно» про нужное ему приложение.
- 📎 Материалы: [решения](./DECISIONS.md), [план](./PLAN.md).

## 2026-10-29 — компактная панель и свой значок

- Азат показал, сколько места занимает окно очереди, и попросил уменьшить его примерно вчетверо. Сделали стеклянную полоску 248 × 48 точек со счётчиком и кнопками. Подписи и горячие клавиши перенесли в подсказки, потому что постоянно показывать их не нужно.
- Нарисовали свой векторный значок стопки снимков. Он используется в строке меню и в иконке приложения.
- Добавили настройки: подтверждение очистки можно включать и выключать. По умолчанию оно включено, архив сохраняется при любом выборе. Сохранение настройки проверили после перезапуска.
- Установили подписанную сборку в «Программы». Рендер и архив прошли проверку, данные очереди совпали с резервной копией.
- ⭐ Азат прислал два новых снимка и комментарии A1–B3. Точки, рамка и стрелки дошли без чёрного поля. Проверку серии после исправления рендера закрыли.
- В точке продолжения уже записано: Snapik удалён после сравнения, его пробные данные и разрешения убраны.
- 🎬 Для истории: после проверки Азат сказал: «Все, кайф, сохраняй результат, завершай сессию».
