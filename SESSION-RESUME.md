# ShotQueue: точка продолжения

## Первый релиз, 2026-10-31

Азат поручил открыть репозиторий и выпустить бесплатную версию без ключей. 0.2.0 (сборка 2), universal arm64/x86_64, macOS 15.2+. Подписанная сборка установлена в `/Applications/ShotQueue.app` и запущена. Репозиторий `ttpa3dhuk/ShotQueue`; публикация 0.2.0 подготовлена, черновики текстов показаны в чате.

- Очередь автоматически архивируется через 5 минут после последнего снимка. Настройки: включение/выключение, 1–1440 минут. Срок сохраняется после перезапуска; во время разметки, вставки и открытых настроек очистка ждёт.
- Счётчик в строке меню, ручная очистка ⌥⌘D с прежней настройкой подтверждения. Снимок ⌥⌘S, вставка серии ⌥⌘V.
- Кнопки семи цветов кисти работают: Азат прислал разноцветный снимок. Инструменты 1–4 показаны значками с цифрами. Прозрачность 10–100%, стиль каждого мазка хранится отдельно.
- Сборка, подпись и автопроверки рендера, архива, клавиатуры, срока и настроек очистки прошли. Вид новых настроек и значков отдельно через GUI не проверяли.
- «О программе» проверено на Mac: версия, сборка, GitHub и добровольный донат по ссылке CueDeck. MIT. ZIP проверен; notarization нет, Gatekeeper отклоняет подпись. Установка скачанного ZIP на чистом Mac и Intel не проверены.
- Данные: `~/Library/Application Support/ShotQueue/`. Последняя резервная копия приложения и данных: `.build/backup-about-20261031-221136/`.

## При следующем продолжении

Проверить ⌥⌘D, настройки времени после перезапуска, копирование комментария при русской раскладке, полный экран через Enter, второй монитор, выбор/удаление метки и ⌘Z/⇧⌘Z. Уже сохранённые снимки пока нельзя редактировать повторно. Тексты первой публикации показаны Азату в этой сессии.
