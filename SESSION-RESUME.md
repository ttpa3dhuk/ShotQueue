# ShotQueue: точка продолжения

## Обновление 2026-11-06

Добавлен переключатель «Запускать при входе в macOS» через SMAppService. Universal-сборка установлена в /Applications/ShotQueue.app, подпись и --self-test проверены. Автозапуск включён по просьбе Азата: --login-status вернул 1 (enabled). Азат увидел уведомление macOS о добавлении программы. Приложение запущено. Готовится установщик 0.2.1; публичный релиз и обновление инструкции требуют согласования черновика. Следующий шаг: проверить запуск после обычного входа/перезагрузки; перезагрузку не выполняли. Резервная копия прежнего приложения: .build/backup-before-autostart/ShotQueue.app. Публичный релиз не обновлён.

## Остановка 2026-11-03

Азат уточнил: снимки нужны только пока находятся в очереди. Установлена сборка, где при очистке снимки и комментарии удаляются; настройка «Сохранять очищенные снимки в архив» по умолчанию выключена. Автоочистка осталась включена на 5 минут. Оба режима проверены на временных данных, галочка проверена в интерфейсе. Старый архив и 11 копий данных очереди по просьбе Азата перемещены в Корзину, не удалены окончательно. README описывает опубликованную 0.2.0.

В установленной рабочей копии добавлена отмена новой метки правым кликом в окне комментария. На Mac проверено: окно закрывается, метка исчезает, следующий номер используется повторно; проверочный снимок отменён, очередь сохранилась. Сборка и встроенные проверки прошли. Правый клик при редактировании существующей метки и отмена незавершённого жеста отдельно на экране не проверены. Публичный релиз 0.2.0 не обновляли.

## Состояние 2026-11-01

Публичный [репозиторий](https://github.com/ttpa3dhuk/ShotQueue), [релиз 0.2.0](https://github.com/ttpa3dhuk/ShotQueue/releases/tag/v0.2.0). Сборка 2, universal arm64/x86_64, macOS 15.2+. На Mac установлена более новая локальная сборка с тем же номером. Бесплатно, MIT; в «О программе» версия, GitHub и добровольная поддержка по ссылке CueDeck.

- В публичной 0.2.0 очередь архивируется через 5 минут после последнего снимка. В локальной сборке архивирование стало необязательным. ⌥⌘S снимок, ⌥⌘V вставка, ⌥⌘D очистка.
- README опубликован с иконкой и восемью кадрами Азата: разметка, комментарий, стрелка/рамка, черновик, отправленное сообщение, панель, счётчик, настройки. Все девять изображений с иконкой проверены рендером GitHub, последние три скачаны с проверкой SHA256.
- Азат подтвердил цвета кисти, клавиши 1–4 и работу захвата после перезапуска 0.2.0. Причина отказа до перезапуска неизвестна. Gatekeeper отклоняет подпись, notarization нет. Intel и установка на чистом Mac не проверены.

## Следующий шаг

Проверить поведение очистки в обычной работе, затем обновить инструкцию перед будущим выпуском. Удалённое хранение снимков Азату не нужно. Установочный ZIP 0.2.0 доступен на GitHub. Mac mini и CueDeck не затрагивали.

Затем уточнить пометку A2 «Инструкция не работает» (ответа о шаге нет); проверить настройки после перезапуска, ⌥⌘D, русскую раскладку, Enter, второй монитор и undo/redo. Сохранённые снимки пока нельзя редактировать повторно.
