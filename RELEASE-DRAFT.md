# ShotQueue 0.2.0

Первый релиз для скачивания. Снимки экрана с пометками и комментариями, очередь и вставка всей серии в Codex. Бесплатно, без ключей и активации.

В этой версии:

- Точка, рамка, стрелка и кисть с номером и комментарием. Инструменты обозначены значками и цифрами 1–4.
- Семь цветов кисти, непрозрачность 10–100%, отмена мазка.
- Счётчик в строке меню, ручная очистка ⌥⌘D и настраиваемая автоочистка. По умолчанию 5 минут после последнего снимка; старые серии сохраняются в локальном архиве.
- «О программе» с версией, сборкой, GitHub и добровольной поддержкой разработки.

## Установка

Нужна macOS 15.2 или новее. Скачать `ShotQueue-0.2.0-mac-universal.zip`, распаковать и перетащить приложение в «Программы». Сборка содержит Apple Silicon и Intel.

Сборка без notarization Apple. Если запуск заблокирован, открыть «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». [Инструкция Apple](https://support.apple.com/102445).

Для снимков разрешить «Запись экрана» и перезапустить приложение. Для вставки серии разрешить «Универсальный доступ». Горячие клавиши: ⌥⌘S снимок, ⌥⌘V вставка, ⌥⌘D очистка.

## Ограничения

Проверено на Apple Silicon. Intel и установка скачанного архива на чистом Mac пока не проверены. Готовые снимки нельзя открыть для повторной разметки. Вставка серии поддерживает Codex для VS Code и приложение Codex. Архивы не удаляются автоматически и занимают место на диске.

Если ShotQueue тебе полезен, можно [поддержать разработку](https://pay.cloudtips.ru/p/b79fa042). Все функции доступны бесплатно.
