# ShotQueue 0.2.1

- Добавлен запуск при входе в macOS. Его можно включить и выключить в настройках ShotQueue.
- При очистке очереди снимки и комментарии удаляются. Сохранение в архив включается отдельно в настройках.
- Новую метку можно отменить правым кликом в окне комментария.

## Установка

Нужна macOS 15.2 или новее. Скачай `ShotQueue-0.2.1-mac-universal.zip`, распакуй и перетащи ShotQueue в «Программы». Сборка для Apple Silicon и Intel.

Сборка пока без notarization Apple. Если macOS заблокировала запуск, открой «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». [Инструкция Apple](https://support.apple.com/102445).

Разреши запись экрана и перезапусти ShotQueue. Для вставки серии нужен «Универсальный доступ».

## Что пока не проверено

Автозапуск зарегистрирован в macOS, но запуск после перезагрузки ещё не проверен. Intel и установка на чистом Mac тоже ждут проверки. Сохранённые снимки нельзя редактировать повторно. Вставка серии поддерживает Codex для VS Code и приложение Codex.

ShotQueue бесплатен. Если программа полезна, можно [поддержать разработку](https://pay.cloudtips.ru/p/b79fa042).
